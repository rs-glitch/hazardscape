# Reviews

These are the gate reports written while the app was built. They are kept as a record.

Each report describes the app at the time it was written. Most findings were fixed afterwards: `BUILD_REPORT.md` lists the fix rounds, and the backlog is in `PROGRESS.md`. Some reports mention test scripts and screenshots. Those are not part of this repo.

| Report | Scope |
|---|---|
| `audit_data.md`, `audit_code.md`, `quality_gate.md` | First release (fires): data, code and final gate |
| `audit_quake.md`, `audit_quake_actionable.md`, `audit_drought.md`, `audit_helene.md` | Data audits for each new tab |
| `CRITIC_DATA.md`, `CRITIC_CODE_UX.md` | Detail-pass gates (data and claims; code and UX) |
| `STRESS_REPORT.md`, `ENGAGEMENT_REPORT.md` | Independent stress and engagement reviews |
| `BUILD_REPORT.md` | What the detail pass built and fixed |
| `ART_DIRECTION.md`, `ART_VFX.md`, `TRACK_IDEAS.md` | Visual-pass reviews and ideas |
| `GATE_P2_ART.md`, `GATE_P2_UX.md`, `GATE_P2_VFX.md` | Phase 2 gates |
